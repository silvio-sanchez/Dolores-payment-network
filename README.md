# Dolores Payment Network

Local payment network for Dolores, Argentina. Electronic cheque with insurance backup.

## Core Rule
A cheque can only be created if:
Day Credits + Insurance >= Cheque Amount

## Daily Settlement
Must finish at zero every day. No exceptions.

## Status
Building the cheque validator with an AI coding assistant.

## Background
20+ years in COELSA, Argentina's central payment clearing house.
Experience in daily settlement, CBU validation, and Y2K migration.
