# Payment Network - Dolores, Argentina

## About Me
My name is Silvio Sanchez. I have 20 years of experience in payment operations at COELSA in Argentina.

I worked with daily settlement, clearing, and reconciliation of bank transfers.

## Project
This project is a Payment Network for Dolores, Buenos Aires.

Goal: Help local shops and people pay and get paid with simple and safe rules.

## Validator
File: validator.py

Rule:
Daily Credits + Insurance >= Amount
Daily settlement must end at zero.

This rule comes from real COELSA operations. If the settlement does not end at zero, the payment is not validated.
